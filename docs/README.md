# lazyclaude

A terminal IDE for Claude Code: a project's GitHub Issues as a board of tickets, and a live Claude Code session a key away.

- [Glossary](glossary.md): the words the code and the docs use
- [Context map](context-map.md): the bounded contexts and how they relate
- [Decisions](adr/0001-record-architecture-decisions.md): the ADRs, why things are the way they are; the sidebar lists the rest
- [Research](research/mkdocs-ecosystem.md): what was read before deciding, one page per question; the sidebar lists the rest
- [Roadmap](roadmap/v1.1.md): the dated plan for each version
- Endpoint maps: one traced call path per endpoint, under `endpoints/` once `/trace-endpoint` has written the first
